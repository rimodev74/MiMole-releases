# MiMole

App Mac gratuite de nettoyage et d'entretien (macOS 15 ou plus récent).

## Installer

1. Téléchargez le fichier `.dmg` de la [dernière version](https://github.com/rimodev74/MiMole-releases/releases/latest).
2. Ouvrez-le et glissez **MiMole** dans **Applications**.
3. Premier lancement : MiMole n'est pas distribuée via l'App Store, macOS la bloque donc une fois.
   Faites **clic droit › Ouvrir** sur MiMole dans Applications, puis **Ouvrir**.
   (Ou : Réglages Système › Confidentialité et sécurité › « Ouvrir quand même ».)
4. MiMole a besoin du moteur open source Mole : dans le Terminal, `brew install mole`.

## Mises à jour

MiMole vérifie seule les nouvelles versions et propose de les installer en un clic
(menu du logo › Rechercher les mises à jour).
